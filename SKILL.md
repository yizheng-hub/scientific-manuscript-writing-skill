# Scientific Manuscript Writing

Turn the supplied evidence into a clear scientific claim, a figure-led evidence chain, a self-contained Supplementary Information document, and publication-ready files. Follow the target journal and supplied templates first. Never transfer project-specific terms, results, or assumptions into a new study.

## Route the task

- For a full manuscript or a substantial revision, read [references/master-prompt.md](references/master-prompt.md) and [references/writing-and-contribution.md](references/writing-and-contribution.md).
- For experimental design, analysis planning, result verification, or reproducibility, also read [references/evidence-and-workflow.md](references/evidence-and-workflow.md).
- For SI, captions, tables, cross-references, or abbreviations, read [references/si-and-captions.md](references/si-and-captions.md).
- For figure planning, plotting, figure review, or visual restyling, read [references/figure-design.md](references/figure-design.md). When the user supplies licensed reference figures, inspect them as visual grammar while preserving the new study's evidence structure.
- For a DOCX deliverable, read [references/word-template.md](references/word-template.md), use [assets/Manuscript Template.docx](assets/Manuscript%20Template.docx), and follow the Documents skill's render-and-inspect gate.
- For final validation, read [references/self-validation.md](references/self-validation.md) and run the relevant reader roles.

## Core workflow

1. Read the journal rules, template, research materials, data, code outputs, current figures, and references. Record missing or unverified inputs without inventing them.
2. State one central scientific claim and map each supporting finding to its analysis, figure panels, innovation, and contribution. Resolve evidence problems before polishing prose.
3. Freeze the verified evidence base. Do not use a preferred direction, ranking, or significance result as the condition for accepting an analysis.
4. Organize Results around scientific findings and figures. Cite and interpret every panel in order. Use conceptual or framework panels only when a Methods overview genuinely needs them; Results panels must carry data or analysis.
5. Build Title, Abstract, Introduction, Discussion, SI, captions, and any cover letter around the same contribution. Keep claims, numbers, terminology, units, colors, and numbering synchronized.
6. Run role-based cold reads for innovation, scientific meaning, broad-reader clarity, defensive writing, evidence alignment, caption self-containment, visual defects, reference support, and Word layout. Fix supported issues and repeat until the relevant roles can recover the intended story accurately.

## Non-negotiable standards

- Do not fabricate data, methods, results, references, or certainty. Mark unresolved facts for verification.
- Remove development logs, failed attempts, stopping records, internal audit labels, AI-review language, and hypothetical reviewer rebuttals from formal deliverables.
- Do not scatter defensive sentences after findings or repeatedly state what the study does not prove. Keep real study-level limitations brief and integrated at the end of Discussion. Preserve conditions or uncertainty that materially change a claim.
- Treat non-positive or null results as evidence when they change the scientific interpretation. State the resulting insight; do not hide it or narrate it as a failed experiment.
- Use simple, idiomatic English. Lead with the innovation and finding, retain only decision-relevant numbers, and explain the contribution before technical detail overwhelms it.
- Define abbreviations independently in the main text, SI, and every figure caption that must stand alone.
- Make captions objective and self-contained; keep interpretation, mechanism, contribution, and extended analysis in the main or SI narrative.
- Do not create Extended Data as part of the default general deliverable. Use the main manuscript and SI unless the user separately requests a journal-specific structure.
- Preserve user edits and template conventions. Make surgical changes, then render and visually inspect every page and every figure at final size.
